## What changed

- New CLI command: `chimera-memory demo [--output-dir <path>]`
- Runs the full value loop in a safe temp workspace
- Shows init → session → wrap → verify → receipt bundle → inspect
- No network, no telemetry, no mutation of current project
- 7 new tests

## Why it matters

- One command shows the complete Chimera Memory experience
- New users see real output before committing to their own project
- Safe by default: uses temp directory, refuses to overwrite non-empty dirs
