# chimera-memory 0.14.0 Release Note

**Theme:** Evidence Bundle Public Trust Hardening

**Release date:** 2026-06-07

---

## What changed

- Receipt bundles now include `README.md` explaining:
  - What each file is (with descriptions)
  - Safety guarantees (no raw ledger, redacted commands, no tokens/paths)
  - What is explicitly excluded (claims.jsonl, sessions.jsonl, etc.)
- 3 new tests guard README presence, safety content, and no private paths

---

## Why it matters

- Users sharing receipt bundles publicly now get clear safety guidance
- Bundle contents are self-documenting
- Reduces risk of accidentally sharing sensitive data

---

## What did not change

- No M2B scoring
- No model ranking
- No routing
- No hosted/cloud
- No dashboard
- No write-import
- No storage format changes
- No GitHub Actions/billing work
