# chimera-memory v0.11.0

**Public Adoption + Output Polish**

## What's New

This release focuses on first-user experience: fixing documentation that confused new PyPI users and adding guard tests to prevent drift.

### Fixes

- **Python version corrected** — README claimed 3.10+, actual requirement is 3.12+
- **Quickstart `wrap` command fixed** — `--scope-path .` was missing from the 5-command example
- **PyPI docs link fixed** — relative link that broke on PyPI now points to source repo
- **Duplicate README section removed** — "Preflight check" duplicated "Preflight Intelligence"
- **Stale wording removed** — evidence dry-run section referenced 0.1.x
- **MacOS Trove classifier corrected** — now `Operating System :: MacOS :: MacOS X`

### Added

- `docs/examples/fresh-install-smoke.md` — full install-to-evidence flow transcript
- `tests/test_public_docs.py` — 10 guard tests preventing docs/metadata drift

## Install

pip install chimera-memory==0.11.0
